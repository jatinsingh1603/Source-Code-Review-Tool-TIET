Identifier classifier: every identifier of a parsed file is decided internal (renamed) or public (kept), by a bundled, versioned public-name allowlist (`data/python.toml` and `data/javascript.toml`, with the language keywords and builtins, the standard-library and allowlisted third-party surfaces, framework contracts and decorators, dunder names, and well-known source, sink and sanitiser names). Every ambiguous or unresolvable case is internal and counted, and an incomplete parse never defaults to public. Dynamic names such as `getattr(obj, "name")` are rewritten consistently when that can be proved; otherwise the name is kept and reported with the allowlist version. The existing setting `privacy.public_allowlist_extra` can only add public names, and every name it adds is kept in clear.
