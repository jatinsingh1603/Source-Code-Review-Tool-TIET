Parsing builds a scope-aware symbol table for Python, JavaScript and TypeScript: every identifier is attributed to exactly one binding (shadowing, `global`/`nonlocal`, comprehensions, `var` hoisting and block scope are resolved as the language does), names with no visible binding are reported as unresolved, `SymbolTable.references(name, scope_id)` returns a binding's definition and uses in source order, `function_ranges` gives exact header, body and full ranges including decorators, and `split_subtokens` splits identifiers on case and character-class transitions without a word list.
