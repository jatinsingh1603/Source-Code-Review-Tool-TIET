Three optional detection layers for redaction: adapters that run Gitleaks and detect-secrets as sandboxed subprocesses, a name recogniser that uses a locally installed spaCy model, and `codekavach privacy terms suggest`, which writes domain-term candidates to the state directory for review and changes no setting. Nothing is enabled by default, and `codekavach doctor` reports whether the name recogniser is installed (`privacy:ner-model`). `tools/detector_eval.py` scores the detectors per subtype on the labelled corpus (CI job `detector-eval`), and the optional engines, models and datasets are listed in a licence manifest.
