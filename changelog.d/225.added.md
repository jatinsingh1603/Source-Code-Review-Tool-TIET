The engine adapter framework (`codekavach.analysis.engines`) runs external analysis engines as sandboxed processes. It adds the `EngineAdapter` contract, a registry that applies the `engines.enabled`, `engines.disabled` and `engines.options` precedence with a licence-attestation gate and a hosted-deployment gate, a pinned-version manifest, a read-only source view that hides repository-supplied engine configuration, a subprocess sandbox and a container sandbox (scrubbed environment, output cap, timeout with process-group kill), a weighted concurrent scheduler with a per-engine result cache, and the `analyse-engines` stage, which degrades and records an item failure instead of aborting the scan. The new `engines.sandbox` settings are restricted keys. An import contract keeps engine packages out of `codekavach`. The author guide is `docs/process/engine-adapters.md`. No concrete engine adapter ships yet (E15, E19 and E20).
