Three default engine adapters under `codekavach.analysis.engines.adapters`, registered in the `codekavach.engines` entry-point group: `opengrep` (SARIF; rules only from `engines.rule_paths`, no registry or network), `bandit` (JSON converted to SARIF, `--ignore-nosec`, hard-coded password values dropped) and `eslint-security` (ESLint with CodeKavach's own flat config, `eslint-plugin-security` and `eslint-plugin-no-unsanitized` from a CodeKavach-owned tools directory; the repository's ESLint configuration is never loaded). Each has a manifest row with licence, pinned version and telemetry decision, an offline recorded conformance case, and a missing engine degrades the stage instead of failing the scan. `engines.options.*.options.tools_dir` is a restricted setting.
