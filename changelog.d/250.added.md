L0, L1 and L2 are plan-driven modes; L0 without a local provider drops the review stage. L1 and L2 now send every file the candidate touches, whole, with up to four times `privacy.slice.max_tokens`; a larger file falls back to the enclosing function and records `fallback_reason = "over_budget"` (ADR-0010, `docs/reference/privacy-levels.md`). The egress guard no longer reads the keys of a JSON request body, which are the provider envelope, so a client identifier such as `content` no longer blocks every request. Policy decisions are recorded per candidate (path-free).
