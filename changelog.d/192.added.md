`docs/guide/cli.md` is a task-oriented guide to the command line: install and `doctor`, a first scan without a key, inspecting what would be sent, privacy levels, providers and consent, working offline, reports, CI pipelines (a GitHub Actions job and a GitLab CI job, with exit-code handling), machine-readable output with `jq` recipes, housekeeping and troubleshooting. A test keeps its commands and options equal to the command tree, and its table of what this build can do equal to the commands' behaviour.
