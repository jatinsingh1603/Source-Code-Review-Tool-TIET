Signature-only stubs for the code a slice calls but does not contain: out-of-slice and cross-file callees, the referenced fields of the enclosing class, and the imports the slice still uses. A stub keeps the name, parameters, annotations and return annotation but never a default value, literal, comment, docstring or body, and carries a one-line syntactic effect summary (returns, which parameter flows to the return value, sanitiser or sink families called, raises) that always ends `derived: syntactic` and never claims safety. Callees on the public allowlist and callees in never-send, vendored, generated or minified files get no stub. Stubs are ranked (data-path callee, other callee, class fields, imports) and the lowest-ranked are dropped first when the slice would go over its token budget; the number dropped is counted by reason. `StubReason` gains `cross_file_callee`, `unresolved_callee`, `class_context` and `import_context`. Python, JavaScript and TypeScript, with 16 new fixture cases.
