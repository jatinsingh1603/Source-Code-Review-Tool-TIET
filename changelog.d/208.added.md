Renamers for Python, JavaScript and TypeScript. A rename plan holds every byte-range edit of one source (identifiers, string literals, comments and docstrings), is checked to be sorted, non-overlapping, on character boundaries and clear of E08 placeholder tokens, and is applied once from the end backwards; a plan that fails the check raises before any text exists. Every internal name gets one token per file, a destructuring or object shorthand `{ accountId }` expands to `{ accountId: var_1 }`, private `#` fields keep their `#`, f-string interpolations are renamed while their literal segments are shaped, strings that name a binding (`__all__`, string annotations, provable `getattr` names) follow it, and a keyword argument stays in clear when the parameter it binds does. `RenamerRegistry` returns a renamer by language. A comment that holds a placeholder token now keeps its delimiters when blanked, so the token is not left as code. `PublicAllowlist.is_public` gives the literal shaper the spelling-only test it expected.
