privacy-prepare and llm-review run the privacy path end to end: per candidate, policy, slice, redaction, pseudonymisation and validation produce a sanitised payload (or a recorded failure), and each payload is sent as one guarded, ledgered request to the selected provider. The mock and replay providers need no network, `--no-send` writes `not_sent_dry_run` entries, and `llm.enabled = false` skips both stages.
