Pseudonymiser literal shaping, number generalisation and comment blanking (E09-03): string literals are shaped per kind so that the SQL skeleton, format specifiers, path separators, URL scheme and regular-expression structure survive while domain vocabulary is replaced, numbers keep only security-relevant values and coarsen the rest to their magnitude, and comments and docstrings are blanked without moving a line. Placeholder tokens pass through unchanged, and a shaped regular expression that no longer compiles is replaced rather than sent.
