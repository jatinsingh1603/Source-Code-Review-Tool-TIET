Secret redaction detectors: a provider pattern pack (`secret.pattern`) covering AWS, Google, Azure, GitHub, Slack, Stripe, Razorpay, Paytm, JWT, private keys, connection strings, npm, PyPI, Docker, Twilio and SendGrid credentials, each keyed on a vendor prefix with a structural validator where the format allows one; a credential-assignment detector (`secret.assignment`) that works on code and on `.env`, YAML and INI files; and a charset-aware entropy detector (`secret.entropy`) with six named false-positive filters. A value repeated more than 20 times in a scan is downgraded, not dropped, and `DetectionReport` counts the downgrades.
