Taint intermediate representation: `codekavach.analysis.taint` now lowers Python, JavaScript and TypeScript functions into a small language-neutral form (assignments, calls, returns, branches, loops, raises and bounded access paths such as `request.args[*]`), builds a control flow graph with exception and loop back edges, and computes reaching definitions and def-use chains. Languages without a lowering (Java, Go, PHP, C# and the rest) raise `LoweringUnavailable` so a scan records a coverage note instead of failing. A new `[taint]` section sets `max_access_path` (default 3), `max_function_nodes` (20,000), `max_blocks` (5,000), `timeout_seconds` (10.0) and `explain`; a function over a cap is skipped and the rest of the file is still lowered. Lowering of an unchanged file is reused through the per-item memo.
