Interprocedural taint: function summaries computed bottom-up over the project call graph (with bounded depth and terminating recursion) let a value read in a request handler be followed into callees in other files, framework route parameters (Flask, FastAPI, Click, Celery) seed the analysis, and an allow-list check that rejects the request clears the flow. The KavachBank sample now reports the SQL injection and the server-side request forgery through their callers.
Interprocedural taint also summarises arguments stored into other arguments, resolves instance method calls within a project, seeds Express route handler parameters, and exposes `taint.max_depth`, `taint.recursion_iterations` and `taint.unknown_callee`.
