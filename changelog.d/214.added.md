Slicing framework and the enclosing-function strategy: a candidate is cut down to the function around it (with decorators), the headers of the classes and functions that enclose it, and the imports the code actually uses, merged into statement-aligned segments that are checked to parse. Code outside any function is cut as a window of whole statements sized from the budget. Over-budget slices shrink in a fixed order and never lose the candidate's lines, the signature or a dominating guard; vendored, generated, minified and never-send files are refused with a named reason. New settings `privacy.slice.default_strategy` and `privacy.slice.max_tokens` (both restricted).
