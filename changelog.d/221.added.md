The egress transport: `Transport.send(request, ticket)` is the only code that opens a connection to a model endpoint. It re-verifies the ticket against the guard (process, expiry, single use, payload hash in the body), then enforces the connection policy: HTTPS only (plain HTTP only to loopback for a declared-local provider), the host allow-list, no IP-literal or credentialed URL, no private or link-local address for a public provider, a header allow-list, no redirects, certificate verification always on, a response size cap and a total deadline. Retries take a fresh ticket each time and never repeat a content-policy refusal; `probe` is a ticketed content-free request; `DryRunTransport` runs every check and sends nothing. Two new settings, `privacy.egress.proxy_url` and `privacy.egress.proxy_trust`, select an explicit proxy (ambient proxy variables are ignored) and record what it may see. `httpx` is added as the single HTTP client; the I1 import contract now also forbids `h11`, `anyio` and `azure` outside the transport, and a test requires every locked distribution to be classified as network-capable or reviewed offline.
