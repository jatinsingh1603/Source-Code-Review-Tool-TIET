Java and Go are now parsed: tree-sitter grammars, identifier, string and comment queries, scoping rules, function ranges and import classification (`java.*` and `javax.*` are the standard library, the `go.mod` module path is the project's own). `codekavach doctor` now reports a grammar check, with the pinned version, for TypeScript, Java and Go as well. See `docs/reference/parsing.md`.
