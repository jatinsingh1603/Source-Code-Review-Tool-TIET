
 Usage: codekavach providers test [OPTIONS] [provider_id]

 Send a constant probe to a provider and report whether it answers.

╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│   provider_id      <str>  Provider id; default: the provider a scan would use.                   │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --model                  <str>                   Model to use for this test.                     │
│ --structured                                     Also run the structured-output probe.           │
│ --accept-egress                                  Approve contacting a remote provider for this   │
│                                                  run.                                            │
│ --timeout                <float range> [x>=1.0]  Seconds allowed per provider. [default: 30.0]   │
│ --all                                            Test every enabled provider in turn.            │
│ --help           -h                              Show this message and exit.                     │
