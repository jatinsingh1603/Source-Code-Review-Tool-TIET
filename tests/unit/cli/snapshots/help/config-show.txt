
 Usage: codekavach config show [OPTIONS] [target]

 Print the configuration in force, masked, optionally with the origin of every key.

╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│   target      <path>  Project directory (default: here).                                         │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --effective                                 Show the effective configuration (default).          │
│                                             [default: True]                                      │
│ --layer                        <str>        Show one layer: default, user, project, profile,     │
│                                             env, cli.                                            │
│ --format                       <toml|json>  Output format. [default: toml]                       │
│ --origin                                    Annotate every key with where its value came from.   │
│ --section                      <str>        Show one top-level table only.                       │
│ --check-secrets                             Report whether each key reference resolves.          │
│ --reveal-domain-terms                       Print privacy.domain_terms in clear.                 │
│ --help                 -h                   Show this message and exit.                          │
