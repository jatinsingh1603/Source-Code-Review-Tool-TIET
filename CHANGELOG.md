# Changelog

All notable changes to CodeKavach are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html). The versioning policy is recorded in [ADR-0004](docs/adr/0004-changelog-and-versioning.md).

Do not edit the sections below by hand. Each user-visible change adds a fragment under [`changelog.d/`](changelog.d/README.md); the fragments are collected into a new section when a release is cut. `make changelog-draft` shows the upcoming section.
