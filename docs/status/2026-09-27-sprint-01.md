## Highlights

- The repository builds and checks itself: `pyproject.toml` with uv, the package skeleton of `docs/ARCHITECTURE.md` section 3, ruff, mypy in strict mode, pytest with test tiers, pre-commit hooks, a Makefile that mirrors CI, and the GitHub Actions workflow.
- The first privacy controls are enforced by tooling: ADR-0003 (single egress point for LLM traffic), ADR-0005 (logging and no telemetry), and import-linter contracts for the invariants.
- The core domain model exists with JSON Schemas in `docs/schemas`: findings with a line-shift-tolerant fingerprint, code slices, the sanitised payload types that cannot be mixed with raw code, LLM verdicts, and egress records with a hash chain.
- Configuration loads in layers (defaults, user, project, profile, command line) through a TOML reader with size, encoding and symlink checks.
- The pipeline core runs: stage protocol, plugin discovery, a content-addressed artefact store, the orchestrator with failure policies (including fail closed with egress lockout), and the `run_scan()` facade.
- The command line starts: `codekavach --version`, global options, the exit-code contract, the JSON output envelope and a `scan` command wired to the orchestrator.
